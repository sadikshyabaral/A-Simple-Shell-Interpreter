## A Simple Shell Interpreter (SSI)

## Description
The shell supports the execution of foreground and background processes, directory navigation, signal handling, and command history (bonus feature).

- foreground commands (working)
- commands with arguments (working)
- cd command with ~ (working)
- background process using bg (working)
- bglist (working)
- SIGINT (Ctrl-C) handling for foreground processes (working)
- prompt showing username, hostname, and current working directory (working)
- command history (bonus feature, working)

## Compliation 
Complie using: 
make

## Running
Run shell with: 
./ssi
